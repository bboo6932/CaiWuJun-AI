# 蔡武君 AI

蔡武君 AI 是一个 macOS 桌面 AI 伙伴原型：有自己的角色形象、语音输入、文本聊天、本地上下文记忆、教学模式和可替换 AI 后端。

## 发布内容

本仓库用于公开发布干净版本，不包含用户聊天记录、API Key、构建缓存或本地隐私数据。

- `PROJECT_PLAN.md`：项目计划与功能路线
- `SUPPORT_US.md`：支持我们说明
- `Support/support-us.png`：支持我们二维码
- `Installers/CaiWuJun-AI-macOS.zip`：macOS 应用安装包
- `CaiWuJun-AI-GitHub-Release.zip`：完整公开发布包

## 主要功能

- macOS 桌面 AI 伙伴窗口
- 根据早中晚显示开场白
- 文本聊天与麦克风语音输入
- 多个独立对话窗口
- 每个窗口独立本地上下文记忆
- 删除窗口时删除对应记忆
- 教学模式
- 系统中文语音朗读
- 眨眼、张嘴、开心、惊讶、生气、伤心等角色状态
- 支持豆包火山方舟、OpenAI、自定义 OpenAI 兼容接口
- 默认可使用本机 Codex CLI 作为 AI 后端

## 使用方式

下载 `Installers/CaiWuJun-AI-macOS.zip`，解压后双击 `蔡武君 AI.app` 打开。

第一次使用语音输入时，macOS 会请求麦克风和语音识别权限。
